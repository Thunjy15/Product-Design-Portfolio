HOW TO PUBLISH FOR FREE USING NETLIFY DROP
1. Extract the ZIP file on your computer.
2. Open https://app.netlify.com/drop in your browser.
3. Drag the extracted folder named "portfolio_site" onto the drop area (or drag the folder's contents if requested).
4. Wait for Netlify to publish the site and generate a public URL ending in netlify.app.
5. Open the generated URL in a private/incognito browser window to test it.
6. You can rename the site from your Netlify site settings to get a cleaner available subdomain.
